# Sales and Marketing Analysis

Statistical analysis of 1,000 historical sales leads for a software-services company. The project examines product profitability, regional performance, conversion rates, deal characteristics, and marketing decisions.

## Files

- [Analysis report](sales-and-marketing-analysis-report.pdf)
- [Stata code](sales-and-marketing-analysis.do)

## Methods

The analysis uses summary statistics, visualizations, correlation, t-tests, chi-square tests, ANOVA, and a two-sample proportion test.

## Running the code

The source data is not distributed with this repository. With authorized access to the original workbook:

1. Save a local copy beside the Stata file as `WSES-sales-leads.xlsx`.
2. Open Stata in this folder.
3. Run `do "sales-and-marketing-analysis.do"`.

## Data and publication note

Only the analysis report and code are shared here. The assigned case, instructions, and source dataset are intentionally excluded because they are third-party course materials.
