# Public-release checklist

Keep the repository private until every item below is complete.

- [ ] Confirm the instructor permits public sharing of completed case answers.
- [ ] Obtain permission from all Group 4 contributors.
- [ ] Obtain publisher permission before adding the IIMB case or dataset.
- [ ] Confirm that `local-only/` files remain ignored and untracked.
- [ ] Review the report and Stata log for information that should remain private.
- [ ] Remove or scrub personal Office metadata from any document approved for publication.
- [ ] Choose a license only for material the group owns and is authorized to license.
- [ ] Recheck `git status` and the staged file list before the first public push.

For a course portfolio, a safer public version is usually a short project summary, selected methodology, and synthetic or independently licensed data rather than the assigned case materials or complete solutions.
